# Sissel — A place to be.

`astra` 分支上的 3D 个人主页 MVP。Three.js + 原生 JavaScript + Vite，无服务端，构建产物可部署到 GitHub Pages。独立实现，没有合并其他分支的页面或代码。

## 本地运行

需要 Node.js 22.12+ 或 24+。

```sh
npm ci
npm run dev
```

打开终端给出的本地地址（默认 http://127.0.0.1:5173）。

```sh
npm test        # 相机转向边界、完整转向范围、不同帧率下的平滑收敛
npm run build  # 生成 dist/
npm run preview
```

## 体验

- Minecraft 式 3D 像素方块建模：硬边家具、阶梯花盆、方块树叶、方块博美犬和悬挂灯笼；材质使用程序生成的 16 × 16 像素贴图，窗景和装饰画采用原创像素绘制。
- 初始面向客厅；相机位置始终固定，水平朝向限制在客厅与书桌之间。
- 移动鼠标环顾，或按住拖动。底部「客厅 / 书桌」按钮直接切换视角；手机可滑动或点按钮。空白区域获得焦点时，也可用键盘左右键切换。
- 电视 → 视频列表，点击条目会在新标签页打开视频网站。
- 电脑 → 个人简介、GitHub 和 ResearchGate 链接、文章。
- 相机 → 相册封面和标题。点开相册直接显示第一张大图，可用按钮或左右方向键逐张浏览。
- 游戏、故事、音乐可从「探索目录」打开 TBA 占位页。
- 房间墙体与地板缩至约 10.45 × 9.3 个场景单位。电视位于前墙，电脑桌紧靠右侧窗墙，窗户就在书桌后方，书柜位于电视和电脑桌之间；固定位置右转 90° 即可正对电脑。沙发和茶几收在左侧，保留中央视线。
- 博美犬「导弹」位于客厅与书桌之间的 45° 朝向上，转到一半时居中并面向观察者。点击模型或名字会随机触发眯眼摇尾巴、抬爪或转圈。也可以通过目录找到它。互动遵循系统的「减少动态效果」设置。
- 镜头统一按鼠标横向位置跟随，经过热点、物体或交互控件时不暂停、不改变转动速度。跨越画布和标签不触发回正；相同鼠标位置始终对应相同目标角度，避免标签移动引发抽搐。
- 弹层支持 Escape 关闭、键盘焦点约束和焦点恢复。右上角的「探索目录」可直接访问所有内容。
- 支持系统「减少动态效果」。
- 无 WebGL 或上下文丢失时，显示普通目录入口，内容仍能访问。

## 修改内容

所有日常编辑的文字、照片、视频与音乐都集中在 `content/` 目录，详细说明见 [`content/README.md`](content/README.md)。

| 文件 / 目录 | 用途 |
| --- | --- |
| `content/profile.md` | 个人简介、研究兴趣与外链（Markdown + YAML frontmatter） |
| `content/articles/` | 文章目录：每个 `.md` 文件（或含 `index.md` 与配图的子文件夹）即一篇文章 |
| `content/photos/` | 相册目录：每个子文件夹即一个相册，可选 `album.yaml` 自定义标题与顺序 |
| `content/videos/videos.yaml` | 视频列表、封面与链接 |
| `content/music/` | 音乐试听文件与 `tracks.yaml` 曲目配置 |
| `src/data.js` | 通过 Vite `import.meta.glob` 汇总 `content/` 内容 |
| `src/content/` | YAML frontmatter 解析、Markdown 渲染与内容加载逻辑 |
| `src/scene.js` | 房间、家具、材质、灯光、拾取与相机 |
| `src/navigation.js` | 相机角度范围、90° 视角切换、鼠标移动判定与平滑函数 |
| `src/dog.js` | 博美犬模型、朝向与互动动作 |
| `src/fixtures.js` | 窗框与摄影相机：部件相接，避免重叠表面引起转动闪烁 |
| `src/plant.js` | 方块植物：圣诞树、仙人掌、垂藤与小花 |
| `src/voxel.js` | 像素材质、统一纹理密度的方块几何体、阶梯轮廓 |
| `src/screens.js` | 像素小电视标识、低清封面、位图字体与低频命令行滚动 |
| `src/main.js` | 内容面板、文章阅读、视频外链、照片浏览 |
| `src/style.css` | 视觉样式与手机布局 |

简介和文章使用示例内容。给 `content/videos/videos.yaml` 的视频条目设置 `url` 即可直达哔哩哔哩或 YouTube 的视频页面。未设置时按标题跳转到哔哩哔哩搜索。

场景模型、电视画面、窗景与装饰画均由代码生成，不依赖外部 3D 模型。字体来自 Google Fonts（DM Sans / Noto Serif SC），不可用时自动回退到系统字体。摄影素材来自 Unsplash，来源见 `content/photos/along-the-way/CREDITS.md`。

圣诞树、窗台仙人掌、垂藤和小花采用不同轮廓与盆色，几何体按材质合并；玩具球使用阶梯球形与三色条纹，合并为三个网格。电视显示像素 bilibili 小电视标识与三张抽象视频封面；电脑展示模拟命令行，每停留 5–7 秒后用 1 秒上移一行，支持减少动态效果。左侧改为横向山水像素画，圣诞树带星顶和彩色挂饰；蓝绿色窗帘和深色钟框与墙面拉开对比。窗户使用真实墙洞、独立窗框和留白窗景。所有材质贴图都在房间销毁时释放。

## GitHub Pages

`npm run build` 输出 `dist/`，使用相对资源路径，兼容根域名与项目子路径。

仓库附带手动触发的 `.github/workflows/deploy.yml`。需要先在仓库 Settings → Pages 将发布来源设为 GitHub Actions；GitHub 的 `workflow_dispatch` 入口要求此 workflow 同时存在于默认分支，然后才可以选择 `astra` 作为运行分支。当前任务只准备本地代码，没有推送、修改仓库设置或发布页面。

## 已验证

- `npm test`：相机边界与不同帧率收敛；重复鼠标坐标持续收敛且不反转；客厅与书桌视角固定相差 90°；狗的三种动作、归位和减少动态效果。
- `npm run build`：静态生产构建成功。
- Chrome 桌面与 390 × 844 手机预览：场景渲染、视角切换、内容面板、文章、照片大图和键盘翻页、Escape 关闭。
- 直接点击 3D 电视不会穿透到新打开面板中的卡片。

Three.js 独立压缩包约 538 KB（gzip 约 133 KB），Vite 会提示其超过默认 500 KB 的 chunk 建议值；这是当前 MVP 的主要运行时依赖。视角和屏幕都静止时不重复绘制；命令行仅在滚动像素变化时更新，静态阴影只计算一次，小狗互动期间限频更新阴影，渲染像素比上限为 1.8。
