# Sissel — A place to be.

`astra` 分支上的 3D 个人主页 MVP。Three.js + 原生 JavaScript + Vite，无服务端，构建产物可部署到 GitHub Pages。独立实现，没有合并其他分支的页面或代码。

## 本地运行

需要 Node.js 22.12+ 或 24+。

```sh
npm ci
npm run dev
```

打开终端给出的本地地址（默认 http://127.0.0.1:5173）。

```sh
npm test        # 相机转向边界、完整转向范围、不同帧率下的平滑收敛
npm run build  # 生成 dist/
npm run preview
```

## 体验

- 初始面向客厅；相机位置始终固定，水平朝向限制在客厅与书桌之间。
- 移动鼠标环顾，或按住拖动。底部「客厅 / 书桌」按钮直接切换视角；手机可滑动或点按钮。空白区域获得焦点时，也可用键盘左右键切换。
- 电视 → 视频列表与可播放、暂停、重播的 12 秒动态分镜占位。
- 游戏机 / 手柄 → 游戏与娱乐文章列表、全文阅读。
- 电脑 → 个人简介、研究兴趣、publication 摘要、非娱乐文章。
- 相机 → 摄影墙、大图、前后翻页；大图支持左右方向键。
- 右侧书柜 → 书影音博客：阅读笔记、电影与音乐随笔，支持全文阅读与返回原分类。
- 沙发朝向电视，茶几位于两者之间；书桌与书柜共同填充右侧视野，右转终点按屏幕比例和书柜包围盒自动计算，书柜完整入镜后即停止，不继续转向空墙。
- 客厅博美犬「团子」→ 点击模型或标签打招呼，支持摸头眯眼、握爪和转圈。目录中也提供入口；尊重减少动态效果设置。
- 镜头统一按鼠标横向位置跟随，经过热点、物体或交互控件时不暂停、不改变转动速度。跨越画布和标签不触发回正；相同鼠标位置始终对应相同目标角度，避免标签移动引发抽搐。
- 弹层支持 Escape 关闭、键盘焦点约束和焦点恢复。右侧 / 底部目录也可直接访问所有内容。
- 支持系统「减少动态效果」，并提供暂停鼠标跟随按钮。
- 无 WebGL 或上下文丢失时，显示普通目录入口，内容仍能访问。

## 修改内容

| 文件 | 用途 |
| --- | --- |
| `src/data.js` | 简介、论文、文章、视频与照片的示例数据 |
| `src/scene.js` | 房间、家具、材质、灯光、拾取与相机 |
| `src/navigation.js` | 相机角度范围、书柜投影边界、鼠标移动判定与平滑函数 |
| `src/dog.js` | 博美犬模型与互动动作 |
| `src/plant.js` | 共享的盆栽模型：弯曲薄叶、中脊渐变、弧形叶柄与盆沿 |
| `src/main.js` | 内容面板、文章阅读、分镜播放、照片浏览 |
| `src/style.css` | 视觉样式与手机布局 |
| `public/images/` | 已下载到本地的示例摄影素材 |

简介、论文作者、日期、文章均明确标记为占位示例，并非真实学术记录。视频目前是动态图片分镜；接入真实视频时，可将 `showVideo` 改成 `<video controls>` 或平台嵌入，并在数据中补上视频 URL。

场景模型、电视画面、窗景与装饰画均由代码生成，不依赖外部 3D 模型。字体来自 Google Fonts（DM Sans / Noto Serif SC），不可用时自动回退到系统字体。摄影素材来自 Unsplash，来源见 `public/images/CREDITS.md`。

四盆植物共享几何体与材质，每盆 2,324 个三角形、4 个网格（原为 7,024 个三角形、20 个网格）。薄叶采用双面不透明材质和顶点颜色，无额外贴图或逐帧动画；该统计是模型预算，不代表整页帧率实测。

## GitHub Pages

`npm run build` 输出 `dist/`，使用相对资源路径，兼容根域名与项目子路径。

仓库附带手动触发的 `.github/workflows/deploy.yml`。需要先在仓库 Settings → Pages 将发布来源设为 GitHub Actions；GitHub 的 `workflow_dispatch` 入口要求此 workflow 同时存在于默认分支，然后才可以选择 `astra` 作为运行分支。当前任务只准备本地代码，没有推送、修改仓库设置或发布页面。

## 已验证

- `npm test`：相机边界与不同帧率收敛；重复鼠标坐标持续收敛且不反转；三种屏幕比例下书柜刚好完整入镜；狗的三种动作、归位和减少动态效果。
- `npm run build`：静态生产构建成功。
- Chrome 桌面与 390 × 844 手机预览：场景渲染、视角切换、内容面板、文章、论文摘要、分镜播放、照片大图和键盘翻页、Escape 关闭。
- 直接点击 3D 电视不会穿透到新打开面板中的卡片。

Three.js 独立压缩包约 538 KB（gzip 约 133 KB），Vite 会提示其超过默认 500 KB 的 chunk 建议值；这是当前 MVP 的主要运行时依赖。静止视角不重复绘制，静态阴影只计算一次，小狗互动期间限频更新阴影，渲染像素比上限为 1.8。
